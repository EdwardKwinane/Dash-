# Skills

Skills are progressive, on-demand procedures. Agents load a skill only when the current task matches its description.

Skills refine procedure; they never override higher-priority rules in `AGENTS.md` or the core standards.

## Available skills

| Skill | When to load |
|-------|--------------|
| `database-migration.md` | Schema changes, migrations, expand/contract work |
| `ai-eval-gate.md` | Any Medium/Large AI change before production promotion |
| `feature-flag-lifecycle.md` | Creating, shipping, or cleaning up feature flags |
| `incident-triage.md` | Production incidents and recovery |
| `new-provider-integration.md` | Adding a third-party provider or external service |
| `adr.md` | Writing or updating Architecture Decision Records |

Add new skills only for procedures that recur and benefit from a focused, checkable checklist.
